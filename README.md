# 💰 Taka Tracker

Taka Tracker is a simple expense-tracking application built with C# in Microsoft Visual Studio. It helps users record and manage their income and expenses.

## ✨ Features

* ➕ Add income and expenses
* 📋 View transaction records
* 🗂️ Organize transactions by category
* 🧮 Calculate total income and expenses
* 💵 Check the remaining balance
* 🖥️ Simple and user-friendly interface

## 🛠️ Technologies Used

* C#
* Microsoft Visual Studio
* Object-Oriented Programming

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project file in Microsoft Visual Studio.
3. Build the project.
4. Press `F5` or click **Start**.

## 🎯 Purpose

This project was created to practise C# programming, object-oriented concepts, and basic financial data management.
